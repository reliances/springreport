## 2. 本机如何打包

在前端工程目录执行：

```bash
cd /Users/mumu/Documents/ReportAllFiles/springreport/SpringReport-ui-vue3

# 安装依赖（首次或依赖变更时）
npm install

# 生产构建
npm run build
```

构建成功后产物在：

```text
SpringReport-ui-vue3/dist/
```

请确认 `vite.config.js` 中：

```js
base: '/jxReport',
```

与 Nginx 的 `location /jxReport/` 保持一致。

## 3. 如何上传到服务器

将 `dist` 目录内容上传到服务器静态目录（覆盖更新）：

```bash
# 示例：清空后上传（注意先备份如需回滚）
ssh root@172.20.20.94 'mkdir -p /home/pub/vue/SpringReport-v3/dist && rm -rf /home/pub/vue/jxReport/dist/*'

scp -r dist/* root@172.20.20.94:/home/pub/vue/jxReport/dist/
```

或使用 rsync：

```bash
rsync -avz --delete dist/ root@172.20.20.94:/home/pub/vue/jxReport/dist/
```

上传后检查：

```bash
ls -la /home/pub/vue/jxReport/dist/
# 应能看到 index.html、static/ 等
```

一般**无需重启 Nginx**；若浏览器仍是旧页面，强制刷新（Cmd/Ctrl + Shift + R）或清缓存。

## 4. Nginx 真实配置（当前服务器）

配置文件路径：

```text
/etc/nginx/conf.d/jxkj-report.conf
```

当前完整内容：

```nginx
server {
    listen       80 default_server;
    server_name  _;

    # 前端静态资源（与 vite base: /JxkjReport 一致）
    location /jxReport/ {
        alias /home/pub/vue/jxReport/dist/;
        index index.html index.htm;
        try_files $uri $uri/ /jxReport/index.html;
    }

    location = /jxReport {
        return 301 /jxReport/;
    }

    # 后端 API 反向代理（对应 application-dev.properties server.port=9099）
    location /SpringReport/api/ {
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header REMOTE-HOST $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_pass http://127.0.0.1:9099/springReport/api/;
    }

    # 协同编辑 WebSocket
    location /SpringReport/api/coedit/websocket {
        proxy_pass http://127.0.0.1:9099/springReport/api/coedit/websocket;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host:$server_port;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 120s;
    }

    # 文件/图片访问：对应后端 file.path=/home/pub/datas/jxreport/images/
    location /images/ {
        alias /home/pub/datas/jxreport/images/;
        charset utf-8;
        autoindex off;
    }

    location = / {
        return 302 /jxReport/;
    }

    access_log  /var/log/nginx/jxkj-report.access.log;
    error_log   /var/log/nginx/jxkj-report.error.log;
}
```

### 修改配置后生效

```bash
nginx -t
systemctl reload nginx
# 或
systemctl restart nginx
```

## 5. 前端依赖的服务器服务

前端本身是静态文件，但完整可用需：

| 服务 | 作用 |
|------|------|
| Nginx | 提供前端页面 + 反代 API/WebSocket/图片 |
| SpringReport（9099） | 业务接口 |
| Redis | 后端依赖 |
| RocketMQ | 协同编辑等后端能力 |

Nginx 启停：

```bash
systemctl start nginx
systemctl stop nginx
systemctl reload nginx
systemctl status nginx
systemctl enable nginx
```

## 7. 常见问题排查

### 7.1 打开页面空白 / 404

```bash
ls /home/pub/vue/JxReport/dist/index.html
# 确认打包 base 是否为 /JxkjReport
# 确认 Nginx location /JxkjReport/ 的 alias 路径正确
nginx -t
tail -n 50 /var/log/nginx/jxkj-report.error.log
```

### 7.2 静态资源 JS/CSS 404

通常是 `base` 与 Nginx 路径不一致。  
`vite.config.js` 的 `base` 必须是 `'/JxkjReport'`，并重新 `npm run build` 后再上传。

### 7.3 页面能开，接口报错 / 跨域 / 502

```bash
# 后端是否监听 9099
ss -lntp | grep 9099
curl -v http://127.0.0.1:9099/springReport/api/login/getMerchantMode

# Nginx 反代是否指向 9099
grep proxy_pass /etc/nginx/conf.d/jxkj-report.conf
tail -n 100 /var/log/nginx/jxkj-report.error.log
```

前端接口前缀为 `/SpringReport/api`（见 `commonUtil.baseUrl`），由 Nginx 转到后端 `/springReport/api/`。

### 7.4 协同编辑 WebSocket 失败

确认 Nginx 中存在：

```nginx
location /SpringReport/api/coedit/websocket { ... }
```

并确认 RocketMQ、后端服务正常。

### 7.5 图片不显示

```bash
ls /home/pub/datas/jxreport/images/
# Nginx /images/ 的 alias 是否指向上述目录
curl -I http://127.0.0.1/images/某文件名
```
